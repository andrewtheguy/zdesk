zDesk

Remote desktop in a browser, for the remote desktop server each platform already has.

  • Download the latest release
  • Source on GitHub
  • Using zDesk
  • Installing zDesk

zDesk is a small gateway you run next to your machines. It connects to:

  • Windows 10 and 11's own Remote Desktop, over RDP with its modern graphics pipeline.
  • macOS's built-in Screen Sharing, in both of its modes: Standard and High Performance.
  • Linux, through wlshare, our own VNC server for wlroots compositors.
  • Other RDP and VNC servers, through each protocol's baseline.

Windows and macOS need nothing installed on the host, only their own sharing switched on. The gateway serves one web page that shows the desktop, so anything with a browser, on Windows, macOS, Linux, iOS or Android, reaches every one of them with no client to install either.

browser ── HTTPS or localhost ── zDesk ── RDP / VNC ── your desktops

The display follows the browser window at its screen density, so a Retina or HiDPI display is sharp and shown at its true size. The remote's own picture is decoded in the browser where the host provides one, with sound, clipboard, two displays in two tabs, and a touch-screen interface for phones and tablets.

Quick start

Install the package for your platform from the latest release. On Debian 13 or Ubuntu 24.04 and later:

curl -fsSLO https://github.com/andrewtheguy/zdesk/releases/latest/download/zdesk-linux-amd64.deb
sudo apt install ./zdesk-linux-amd64.deb

Installing zDesk covers every platform, and Using zDesk the browser client and setting up Windows, Mac, wlshare and VNC targets.
